Servidor MCP de CoopGames

Un servidor MCP gratis y de solo lectura para que los asistentes de IA respondan «¿a qué jugamos?». Busca en el catálogo de juegos cooperativos y multijugador de CoopGames por jugadores, plataformas, crossplay, cooperativo en el sillón y precio.

https://coopgames.app/mcpStreamable HTTP · sin autenticación · nombre en el registro app.coopgames/coopgames

Conectarlo

Claude Code

claude mcp add --transport http coopgames https://coopgames.app/mcp

Claude (web y escritorio)

Configuración → Conectores → Agregar conector personalizado → pega https://coopgames.app/mcp.

Cursor ~/.cursor/mcp.json

{ "mcpServers": { "coopgames": { "url": "https://coopgames.app/mcp" } } }

VS Code .vscode/mcp.json

{ "servers": { "coopgames": { "type": "http", "url": "https://coopgames.app/mcp" } } }

Cualquier otro cliente que acepte servidores MCP remotos por HTTP funciona con la misma URL.

Herramientas

search_gamesBuscar juegos para un grupo: jugadores (2–8), plataformas, online o misma pantalla, cooperativo o versus, género, crossplay, gratis, una copia para todos.
get_gameTodo lo multijugador de un juego: plataformas, jugadores, crossplay entre cada par de plataformas, duración de la partida.
crossplay_checkSí o no rápido: ¿puede alguien en la plataforma A jugar este juego con alguien en la plataforma B?

Plataformas: PC, PS5, PS4, Xbox, Switch y Switch 2. Cada resultado enlaza a la página del juego en CoopGames. Las respuestas vienen en inglés.

Ejemplos

  • «Somos cuatro para jugar esta noche: dos en PC, uno en PS5 y uno en Xbox. ¿Qué tiene crossplay?»
  • «Juegos cooperativos gratis para 3 en Switch»
  • «¿Puedo jugar Helldivers 2 con un amigo que está en Xbox si yo estoy en PS5?»
  • «Juegos para dos en el sillón en PS5»

Límites

  • Solo lectura. Nunca escribe nada.
  • Hay un límite de pedidos por IP. Si recibes 429, espera un minuto.
  • Si usas los datos, cita a CoopGames y enlaza la página del juego.
