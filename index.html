CoopGames MCP server

A free, read-only MCP server that lets AI assistants answer "what can we play together?". It searches the CoopGames catalog of co-op and multiplayer games by players, platforms, crossplay, couch co-op and price.

https://coopgames.app/mcpStreamable HTTP · no auth · registry name app.coopgames/coopgames

Connect it

Claude Code

claude mcp add --transport http coopgames https://coopgames.app/mcp

Claude (web and desktop)

Settings → Connectors → Add custom connector → paste https://coopgames.app/mcp.

Cursor ~/.cursor/mcp.json

{ "mcpServers": { "coopgames": { "url": "https://coopgames.app/mcp" } } }

VS Code .vscode/mcp.json

{ "servers": { "coopgames": { "type": "http", "url": "https://coopgames.app/mcp" } } }

Any other client that supports remote MCP servers over HTTP works with the same URL.

Tools

search_gamesFind games for a group: players (2–8), platforms, online or same screen, co-op or versus, genre, crossplay, free-to-play, one copy for everyone.
get_gameThe full multiplayer picture of one game: platforms, player counts, crossplay between every pair of platforms, session length.
crossplay_checkA quick yes or no: can someone on platform A play this game with someone on platform B?

Platforms: PC, PS5, PS4, Xbox, Switch and Switch 2. Every result links to the game's page on CoopGames.

Example prompts

  • "Four of us want to play tonight: two on PC, one on PS5, one on Xbox. What has crossplay?"
  • "Free co-op games for 3 players on Switch"
  • "Can I play Helldivers 2 with a friend on Xbox if I'm on PS5?"
  • "Couch co-op games for two on PS5"

Limits

  • Read-only. It never writes anything.
  • Rate limited per IP. If you get 429, wait a minute.
  • Please cite CoopGames and link to the game's page when you use the data.
